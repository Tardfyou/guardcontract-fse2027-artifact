\section*{Data Availability}
\label{sec:data-availability}

An anonymous replication package has been assembled with controlled program
sources and SDK observations, reference outcomes and the fixed split, prediction
records, ecological compilation/admission/risk records, strict-verifier outputs,
async controls, and repair-control results. It also contains analysis scripts
and environment locks. The package retains the different evidence populations
and output types rather than replacing them with pooled outcome counts.
The provided reviewer-facing proxy link for this base package is the
\href{https://anonymous.4open.science/r/guardcontract-fse2027-artifact-88B0}{anonymous reviewer link}.

The current package has 1,107 manifest-listed files, plus the manifest and
checksum list. Every listed size and SHA256 was verified. Offline reconstruction
from package-relative inputs exactly reproduces the canonical aggregate tables
without network access or model calls (R0/R1). This establishes reproduction of
the packaged computations, not semantic validation of the risk candidates or
a fresh reproduction of commercial-model outputs.
For 37 ecological JSON files, source-language prose and path labels are provided
as English derived views. The package records original-file and original-path
hashes; these views preserve identifiers, labels, and numeric values but are not
byte-identical source records or independently validated translations.

Raw provider wires, local credentials, third-party source copies, and virtual
environments are excluded. Pinned source identities and derived evidence
retain traceability subject to the relevant redistribution permissions.
The completed source-adjudication results comprise 137 per-candidate records
linked to the frozen contract IDs, 14 local PoC scripts supporting 18 records,
and an aggregate analysis. These records are outside the current anonymous
package and are not covered by its R0/R1 claim. Before they
can enter an anonymous reviewer package, linkable defect labels and PoCs need
coordinated-disclosure, anonymity, redistribution, and checksum review. The
manuscript reports aggregate counts without identifying affected repositories.
